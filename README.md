Mimingventures!

is a fast-paced 2D catcher game set in a pixel-art city alley. Guide a hungry orange cat left and right to catch falling treats and rack up points, but watch out for the junk raining down with them. You have three lives, and every hazard you catch costs you one. Each level makes items fall faster and spawn more often, so how long can you keep up? When the game ends, you’ll see your score and your highest score, then hit Try Again to beat it.

Week 3: Level Design
Main script now tracks a level that goes up every 10 treats caught. Each level makes new items fall faster and spawn more often, using a few tuning constants at the top of the script. The HUD also receives the level so it can display it, and there’s a safety check so a missing Item Scene shows an error instead of crashing the game.
